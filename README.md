# HRMS
HRMS for Build with Bharat 4.0 Hackathon - Java 25 + Spring Boot 4.1

HRMS is a web-based application designed to manage employee and HR-related activities in one place.

Features

- Employee Management
- Department Management
- Attendance Management
- Leave Management
- Role-Based Access
- HR Dashboard
- Reports

Tech Stack

- Java
- Spring Boot
- PostgreSQL
- Thymeleaf
- Tailwind CSS
