COPY COMMANDS (from project root)
==================================

1. Copy HrmsApplication.java to root of com/hrms package:
   cp spring-boot-starter-files/java/HrmsApplication.java src/main/java/com/hrms/

2. Copy HealthController to controller package:
   cp spring-boot-starter-files/java/HealthController.java src/main/java/com/hrms/controller/

3. Copy SecurityConfig to config package:
   cp spring-boot-starter-files/java/SecurityConfig.java src/main/java/com/hrms/config/

4. Copy exceptions to exception package:
   cp spring-boot-starter-files/java/ResourceNotFoundException.java src/main/java/com/hrms/exception/
   cp spring-boot-starter-files/java/BusinessException.java src/main/java/com/hrms/exception/
   cp spring-boot-starter-files/java/GlobalExceptionHandler.java src/main/java/com/hrms/exception/

5. Copy application.yml to resources:
   cp spring-boot-starter-files/resources/application.yml src/main/resources/

6. Copy Flyway migration:
   cp spring-boot-starter-files/resources/db/migration/V1__initial_schema.sql src/main/resources/db/migration/

FILE CONTENTS SUMMARY
====================

1. HrmsApplication.java
   - Location: src/main/java/com/hrms/
   - Type: Main Spring Boot class
   - Annotations: @SpringBootApplication
   - Purpose: Entry point for the application
   - Dependency: None

2. HealthController.java
   - Location: src/main/java/com/hrms/controller/
   - Type: REST Controller
   - Endpoint: GET /api/health
   - Purpose: Health check for deployment systems
   - Dependency: Spring Web

3. SecurityConfig.java
   - Location: src/main/java/com/hrms/config/
   - Type: Spring Configuration class
   - Features: Password encoding (BCrypt) + CORS config
   - Purpose: Security setup for the application
   - Dependency: Spring Security

4. ResourceNotFoundException.java
   - Location: src/main/java/com/hrms/exception/
   - Type: Custom RuntimeException
   - When thrown: Resource not found (404)
   - Used by: Services when entity lookup fails
   - Dependency: None

5. BusinessException.java
   - Location: src/main/java/com/hrms/exception/
   - Type: Custom RuntimeException
   - When thrown: Business rule violation (400)
   - Used by: Services for validation failures, insufficient data, etc.
   - Dependency: None

6. GlobalExceptionHandler.java
   - Location: src/main/java/com/hrms/exception/
   - Type: REST Controller Advice (AOP)
   - Purpose: Centralized exception handling
   - Handlers:
     * ResourceNotFoundException → 404
     * BusinessException → 400
     * All other exceptions → 500
   - Dependency: Spring Web

7. application.yml
   - Location: src/main/resources/
   - Type: YAML configuration file
   - Contains:
     * Database connection (PostgreSQL)
     * Flyway migration config
     * JPA/Hibernate settings
     * Logging configuration
     * Server settings (port 8080)
   - Dependency: None (YAML file)

8. V1__initial_schema.sql
   - Location: src/main/resources/db/migration/
   - Type: SQL migration script (Flyway)
   - Naming: V{VERSION}__{DESCRIPTION}.sql
   - Purpose: Database schema baseline
   - Dependency: PostgreSQL/Flyway
